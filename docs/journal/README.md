# Journal

Free-form, dated notes. Captures the evolution of thinking — questions
asked, answers discovered, reasoning that changed when new evidence
came in.

One file per month: `2026-05.md`, `2026-06.md`, etc. Newest entries at
the top of each file. Timestamp entries to at least the hour, minutes
when several land in the same hour. ISO format throughout.

If a piece of reasoning gets overturned later, don't delete the
original entry — strike through (`~~like this~~`) and add a follow-up
that explains what changed. The "why we changed our mind" thread is
the whole point of keeping a journal.

Compact prose is fine. Most reasoning fits in the journal directly.
Pull a separate design doc only when there's real reference material
that engineers will re-read (file layout, invariants, phase plans).
Tradeoff analyses, options considered, false starts — keep those here.
